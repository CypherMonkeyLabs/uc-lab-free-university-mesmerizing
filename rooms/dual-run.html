T7 · T7-R02

Dual-run and rollback

ExportSVGPNGHTMLSheet

Learn it in 5 minutes

  • Move one number you can give back.
  • Keep the old route until the new path passes a scripted test.
  • Rollback is a planned route, not a hope.
  • Porting a carrier number is slower than changing a lab route.
  • Evidence is a call, a ladder, and a user check.

Visual

What is going on

Dual-run means the same business number can still be delivered the old way while you prove the new way, or that you can return it quickly. Carrier ports do not always allow an instant return. Say which kind of move you are doing before the night of the change.

Confirm before relying. Confirm porting lead times with the carrier. This lab does not know your contract.

Worked example

A DID is translated to Webex Calling for a day, with the CUCM translation pattern saved. The test call fails caller ID. You put the old translation back and attach both INVITEs to the ticket. That is a rollback, not a defeat.

Quiz

1. A carrier port can always be undone in five minutes.

False. Confirm the porting rules.
