Hooks to leave in a design

  • SIPREC on the SBC, so a future recorder has a defined leg. RFC 7866.
  • CTI or the platform's webhook with a stable interaction id, so CRM and WFM can subscribe later.
  • A test number that is not 911, routed like production, so each bridge has a canary.
  • +E.164 on every boundary, so the next system does not invent its own habit.

None of these hooks place a call by themselves. They are names of interfaces you can write into a design review.
