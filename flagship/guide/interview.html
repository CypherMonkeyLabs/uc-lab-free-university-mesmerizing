A path, not a salary table

This lab does not publish wages. Hiring pages move, and a number here would be a guess. The work itself has a readable order:

  1. Voice and SIP. You can draw registration and a basic call, and you can say why a 200 OK is not audio.
  2. Call control and the SBC. You can explain a CSS miss versus dial-peer 0 versus a carrier timeout.
  3. Cloud PSTN. You can name Calling Plan, local gateway, Operator Connect, and Direct Routing without mixing their traces.
  4. Contact center and the systems around it. Call type or entry point, then recording, WFM, CRM, and a virtual agent that can hand off.

Cisco's February 2026 certification set is one public map of that work: CLCOR, then a concentration. It is not the only way to be hired. The certifications page has the exam names and the blog link.
