Exams as of the February 2026 Cisco update

Certifications

This lab is not an exam dump and it is not official training. The names below are the public exam names so you can aim your reading.

ExamWhat Cisco published
350-801 CLCORImplementing Cisco Collaboration Core Technologies. 120 minutes. Core for CCNP Collaboration and CCIE Collaboration. v2.0 topics start 3 February 2026. v1.2 testing ended 2 February 2026.
300-815 CLACCImplementing Cisco Advanced Call Control On-Premises. v2.0 is a 90-minute concentration. Cisco's topic page includes signaling and media, CUBE, dial plan, and mobility.
300-820 CLHCTImplementing Cisco Collaboration Hybrid and Cloud Technologies. Updated to v2.0 on the same February 2026 date, per Cisco's learning blog.
300-830 CLCCEImplementing Cisco Collaboration Cloud Customer Experience. Cisco's February 2026 blog introduces this concentration.

CCNP Collaboration remains a core exam plus one concentration. The blog describes the v2.0 set as a 50/50 split between cloud and on-premises topics. Confirm the live blueprint before you book a seat. Prices on Cisco's pages move.

Microsoft publishes Teams Phone and collaboration certifications on Microsoft Learn. Confirm the current exam code there. This lab does not freeze a Microsoft exam number that the page you book might already have replaced.
