Cheat codes

Flip a card. The back is the short read. The sheet, PDF, and PNG are the one-page files. Vendor books stay at the links on each study page.

Ports and protocolsFlip5060 SIP, 5061 TLS, 2000 SCCP, 69 TFTP, 6970 HTTP. From the CUCM 15 port chapter.Sheet · PDF · PNG
Firewall matrixFlipPhones to CUCM, gateways, applications, then CUCM outward. The matrix is the sheet, not a live ACL.Sheet · PDF · PNG
Call flowsFlipREGISTER stores a binding. The call is not up until ACK. A 200 OK is not audio.Sheet · PDF · PNG
Configuration checklistFlipLine CSS before device CSS. Early offer is SDP in the INVITE. Delayed offer is SDP in the 200.Sheet · PDF · PNG
Troubleshooting treeFlipOne leg, one identifier, one change, then the capture. Reorder outside is often CSS before CUBE.Sheet · PDF · PNG
GlossaryFlipCSS, partition, dial-peer 0, early offer, B2BUA, ELIN, call type, EF 46.Sheet · PDF · PNG
PSTN optionsFlipCUCM trunk, Webex Calling Plan or local gateway, Teams Calling Plan or Operator Connect or Direct Routing.Sheet · PDF · PNG
EmergencyFlipDirect 911 in the US. Callback must return to the site that dialed. Name the product before the test.Sheet · PDF · PNG
QoSFlipVoice RTP is commonly EF 46. Cisco signaling designs often use CS3. RFC 4594 assigns signaling CS5.Sheet · PDF · PNG
CutoverFlipDiscover, normalize to +E.164, canary including callback, write the rollback, stop if proof is missing.Sheet · PDF · PNG
SecurityFlipTLS locks signaling. SRTP locks audio. 8090 is gateway recording HTTP. Consent is not a port.Sheet · PDF · PNG
WFM and recordingFlipSame agent id, same interval, contact-center timezone. A forecast does not route the call.Sheet · PDF · PNG
FlashcardsFlipTwelve cited cards on the printable page. The JSON files hold the full decks.Sheet · PDF · PNG
