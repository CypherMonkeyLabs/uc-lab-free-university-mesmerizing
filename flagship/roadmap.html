Study timeline

Roadmap

This is a reading order and a few dated public facts. It is not a vendor's product roadmap.

WhenWhat is public
2002RFC 3261 obsoletes the first SIP RFC and is still the call-setup reference.
2018Kari's Law and RAY BAUM'S Act set MLTS duties in the United States: direct 911, notification, and a dispatchable location.
3 Feb 2026Cisco starts CCNP Collaboration v2.0 testing: CLCOR, CLACC, CLHCT, and the new CLCCE concentration. The blog calls it a 50/50 cloud and on-premises split.
This labLearn the leg first. Add cloud PSTN only after you can name which product owns the number. Add WFM, QM, CRM, and virtual agents only after the call has an id they can share.

Your next 12 sessions

  1. Registration, basic call, SDP.
  2. Dial plan and the CSS lab.
  3. Hold, transfer, hunt, voicemail.
  4. CUBE and the PSTN ladder.
  5. One-way audio and OPTIONS.
  6. MRA and certificates, as symptoms, not as a rebuild.
  7. Emergency and QoS.
  8. Webex local gateway and Teams Direct Routing, side by side.
  9. Migration dual-run.
  10. UCCE call type and Webex Contact Center entry point.
  11. Ecosystem: recording, WFM, CRM, virtual agent.
  12. Ten quiz questions and one branching case, written up as leg, id, counter, capture.
