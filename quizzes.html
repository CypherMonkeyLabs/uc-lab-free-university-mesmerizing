Quizzes

SIP transactions and dialogs. A 180 Ringing means the call was answered.

False. It means alerting. The 200 accepts the session.

SIP transactions and dialogs. ACK for a 2xx is optional.

False. Without ACK the far end retransmits the 200 and can drop the call.

Offer and answer. The answer may add a codec the offer did not list.

False. The answer narrows the offer.

Registration. REGISTER creates a voice session.

False. It stores a Contact binding.

Early media and PRACK. Hearing ringback proves the called party answered.

False. Ringback can be early media.

Partitions and calling search spaces. CUCM searches every partition and picks the longest match across all of them.

False. It walks the CSS in order.

Route patterns, lists, and groups. A route group is a list of partitions.

False. It is a list of gateways or trunks.

Transformations. The calling number and the called number are the same field.

False.

SIP trunks on CUCM. A SIP trunk in service proves the route pattern points at it.

False. Routing and status are separate.

Dial peers. Outbound dial-peer preference is consulted before match length.

False. Longest match comes first when hunt is the default.

CUBE as a B2BUA. CUBE forwards one SIP dialog unchanged, like a proxy.

False. It is a B2BUA.

SRST. SRST automatically clones every CUCM hunt pilot.

False.

Local gateway toward Webex Calling. A local gateway registration is the same object as a CUCM phone registration.

False. It is the trunk from CUBE toward Calling.

Expressway-C and Expressway-E. Every CUCM call must pass through Expressway.

False.

Mobile and Remote Access. MRA replaces CUCM as the registrar.

False. CUCM remains the registrar.

Firewall and traversal. A completed INVITE proves the firewall allows RTP.

False.

DSCP and the trust boundary. EF and CS3 are the same mark.

False. EF is DSCP 46. CS3 is a different codepoint.

LLQ and the delay budget. LLQ adds bandwidth to a circuit.

False. It schedules the bandwidth you already have.

Locations and call admission control. CUCM locations mark RTP as EF.

False.

UCCE from carrier to agent. Queue music means an agent phone is ringing.

False. Treatment happens before delivery.

The CUCM bridge into UCCE. A successful ICM script guarantees CUCM can ring the phone.

False.

Webex Contact Center beside UCCE. An ICM script runs unchanged inside Webex Contact Center.

False.

Webex Calling and Dedicated Instance. Dedicated Instance uses the same dial-plan objects as multi-tenant Calling.

False.

Dual-run and rollback. A carrier port can always be undone in five minutes.

False. Confirm the porting rules.

Survivability during cutover. SRST protects Webex Calling apps with no extra design.

False.

One hypothesis, one change. Changing the CSS, the codec, and the gateway in one window is a clean test.

False.

Reading a ladder. Two Call-IDs mean the trace is corrupt.

False. A B2BUA creates two dialogs.

One-way audio. A 200 OK with SDP proves two-way audio.

False.

Direct dial, notification, and location. Kari's Law, as the FCC page describes it, is satisfied by requiring users to dial 9 before 911.

False. The page says direct dialing means no prefix or access code such as 9.

Direct dial, notification, and location. This lab page is legal advice for every country.

False. It is a study note about pages that were opened. Confirm the rule where you operate.

Emergency Responder, ERL, and ELIN. An ELIN is the caller's directory number.

False. The CUCM chapter describes the ELIN as the number Emergency Responder uses for routing and PSAP callback, mapped back to the extension.

Emergency Responder, ERL, and ELIN. A phone on a switch Emergency Responder does not know is still located.

False. The planning chapter calls those phones unlocated.

On-site alert, callback, and what this lab will not decide. An outbound 911 test proves PSAP callback.

False. Callback is a separate call toward the ELIN.

Phone fork and network fork. A 200 OK proves the recorder received both audio directions.

False. The fork is a separate media path.

Phone fork and network fork. The built-in bridge on one phone always follows the cluster-wide parameter.

False. The feature guide says the phone setting overrides the cluster default when default is not selected.

SIPREC and CUBE as the recording client. The recording INVITE is the same dialog as the call being recorded.

False. SIPREC is a separate recording session.

Compliance is a reason, not a setting. RFC 7245 chooses the retention period for your contact center.

False. It explains recording architectures. It does not set your policy.

A SIP trunk is a peer, not a brand. One SIP trunk means both PBXs share one dial plan.

False. Each side matches the digits with its own rules.

Asterisk and FreeSWITCH as the other PBX. An Asterisk dialplan is a CUCM calling search space.

False. It is a different object on a different product.

WebRTC, SIP over WebSocket, and a hosted bridge. A WebRTC page is a CUCM SIP phone.

False. Something has to translate, unless the far end also speaks WebRTC.

WebRTC, SIP over WebSocket, and a hosted bridge. RFC 8829 replaces SIP.

False. It describes JavaScript control of the signaling plane and how that relates to existing signaling.
