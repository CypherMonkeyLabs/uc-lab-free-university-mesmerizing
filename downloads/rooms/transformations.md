# Transformations

- Called, calling, and redirecting numbers are different fields.
- A mask can fix or break caller ID.
- Translation patterns change digits and can change the CSS.
- External phone number masks are a presentation tool.
- Write the digits before and after each step.

Most 'wrong caller ID' tickets are a mask on the route pattern, the route list, or the trunk, applied in an order the engineer did not draw. Capture the outgoing INVITE and compare it with the directory number.

Users dial 9 and a national number. The pattern strips the 9 and prefixes the carrier's expected digits. The calling number is masked to the site's main number. If the mask is the directory number instead, the carrier may reject the call.
