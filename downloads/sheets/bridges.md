# Open telephony bridges

- A SIP trunk joins two dial plans. It does not merge them.
- SIPconnect is the SIP Forum recommendation for provider peering.
- Asterisk and FreeSWITCH are separate PBXs with their own dialplans.
- WebRTC is a browser API plus the protocol suite in RFC 8825. SIP over WebSocket is RFC 7118.
- A CPaaS vendor matrix was not opened. Confirm a vendor on that vendor's page.
